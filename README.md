# 🎓 بوت مراقب LMS - Telegram Bot

> بوت تلجرام يفحص مواد Moodle دورياً ويرسل تنبيهات عند اكتشاف واجبات أو كويزات أو موارد جديدة. يعتمد وقت وصول التنبيه على فترة الفحص المختارة.

---

## 🚀 خطوات التشغيل

### الخطوة 1: إنشاء بوت تلجرام

1. افتح تلجرام وابحث عن **@BotFather**
2. أرسل `/newbot`
3. اختر اسماً للبوت (مثال: `LMS Monitor`)
4. اختر username للبوت (مثال: `mutah_lms_bot`)
5. ستحصل على **Token** - احفظه

### الخطوة 2: إضافة Token إلى ملف .env

افتح ملف `.env` وضع الـ Token:

```
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
```

### الخطوة 3: تثبيت المتطلبات

```powershell
pip install -r requirements.txt
```

### الخطوة 4: تشغيل البوت

```powershell
python bot.py
```

---

## 📱 كيفية الاستخدام

بعد تشغيل البوت، افتح تلجرام وابدأ المحادثة:

| الأمر | الوظيفة |
| `/start` | تشغيل البوت وفتح لوحة التحكم الرئيسية بالأزرار |
| `📱 لوحة التحكم` | زر القائمة السفلي وداخل الشات لفتح تطبيق Telegram Mini App التفاعلي |
| الأزرار | استيراد المواد تلقائياً بنقرة واحدة، إدارة المواد، تشغيل/إيقاف المراقبة، الفحص اليدوي، الإعدادات والإحصائيات |

أثناء تشغيل المراقبة، يرسل البوت طلباً خفيفاً لنظام الجامعة كل دقيقتين للمحافظة على الجلسة نشطة. إذا انتهت الجلسة، يوقف الفحص ويرسل تنبيهاً مع زر إعادة تسجيل الدخول؛ تبقى المواد وإعدادات المراقبة محفوظة، ويستأنف البوت المتابعة بعد نجاح الدخول.

## ⚙️ إعدادات متقدمة

في ملف `config.py`:

```python
# فترة الفحص الافتراضية (بالدقائق)
CHECK_INTERVAL_MINUTES = 10
```

الفترة الافتراضية والفترة المحفوظة حالياً على 5 دقائق تنتقل إلى 10 دقائق عند تشغيل التحديث. يمكن تغييرها لاحقاً من إعدادات البوت.

## 🔔 أنواع الإشعارات والمميزات الذكية

- **📚 واجب جديد وتتبع حالة التسليم:** يرصد البوت الواجبات ومواعيدها بدقة. إذا قام الطالب بحل وتسليم الواجب في LMS، يكتشف البوت ذلك فوراً ويتوقف عن إرسال تنبيهات الموعد المتبقي (24 ساعة / 3 ساعات / ساعة واحدة) لتجنب الإزعاج.
- **📝 كويز جديد:** مع الموعد ورابط الكويز وحالته.
- **📎 إرسال الملفات والمستندات مباشرة:** عند نزول سلايدات أو ملفات PDF أو ملخصات جديدة، يقوم البوت بتحميلها وإرسالها مباشرة كـ مستندات Telegram Document داخل المحادثة.
- **⚡ نظام الفحص المشترك (Shared Course Scraping):** عند اشتراك عدة طلاب في نفس المادة، يفحص البوت المادة مرة واحدة في الدورة ويشارك المحتوى في الذاكرة المؤقتة (Cache)، مما يقلل عدد الطلبات على خوادم الجامعة بنسبة 90% ويحمي من حظر الـ IP.

## 🛡️ الأمان

- **تشفير كلمات المرور:** تُشفر كلمات المرور آلياً باستخدام خوارزمية التشفير المتماثل `AES / Fernet` قبل تخزينها في قاعدة البيانات (سواء كانت SQLite أو PostgreSQL)، ويتم اشتقاق مفتاح التشفير من متغيرات البيئة أو ضبط `ENCRYPTION_KEY` مخصص في `.env`.
- يحاول البوت حذف رسائل بيانات الدخول من تيليجرام فور استلامها لحماية خصوصية الطالب.

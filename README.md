# 🎓 بوت مراقب LMS - Telegram Bot

> بوت تلجرام يراقب نظام التعليم الإلكتروني (Moodle) ويُرسل إشعارات فورية عند نزول واجبات أو كويزات جديدة.

---

## 🚀 خطوات التشغيل

### الخطوة 1: إنشاء بوت تلجرام

1. افتح تلجرام وابحث عن **@BotFather**
2. أرسل `/newbot`
3. اختر اسماً للبوت (مثال: `LMS Monitor`)
4. اختر username للبوت (مثال: `mutah_lms_bot`)
5. ستحصل على **Token** - احفظه

### الخطوة 2: إضافة Token إلى ملف .env

افتح ملف `.env` وضع الـ Token:

```
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
```

### الخطوة 3: تثبيت المتطلبات

```powershell
pip install -r requirements.txt
```

### الخطوة 4: اختبار الاتصال بـ LMS (اختياري)

```powershell
python test_scraper.py
```

### الخطوة 5: تشغيل البوت

```powershell
python bot.py
```

---

## 📱 كيفية الاستخدام

بعد تشغيل البوت، افتح تلجرام وابدأ المحادثة:

| الأمر | الوظيفة |
| `/start` | تشغيل البوت وفتح لوحة التحكم الرئيسية بالأزرار |
| `/login [student_id] [password]` | تسجيل الدخول إلى LMS (أو عبر الزر) |
| `/courses` | عرض موادي المسجلة |
| `/monitor` | تشغيل المراقبة التلقائية |
| `/stop` | إيقاف المراقبة |
| `/check` | فحص فوري الآن |
| `/status` | عرض الحالة والإحصائيات |
| `/logout` | تسجيل الخروج |

## 📂 هيكل المشروع

```
LMS_Monitor/
├── bot.py            # البوت الرئيسي
├── lms_scraper.py    # سحب البيانات من LMS
├── monitor.py        # محرك المراقبة الدورية
├── database.py       # قاعدة البيانات SQLite
├── config.py         # الإعدادات
├── test_scraper.py   # اختبار الـ scraper
├── .env              # متغيرات البيئة (Token)
├── requirements.txt  # المتطلبات
└── lms_monitor.db    # قاعدة البيانات (تُنشأ تلقائياً)
```

## 🛡️ الأمان

- **كلمات المرور** تُحفظ محلياً في قاعدة بيانات SQLite على جهازك فقط
- الرسائل التي تحتوي على كلمة المرور تُحذف فوراً من التلجرام
- البيانات لا تُرسل لأي خادم خارجي

# 🎓 بوت مراقب LMS - Telegram Bot

> بوت تلجرام يفحص مواد Moodle دورياً ويرسل تنبيهات عند اكتشاف واجبات أو كويزات أو موارد جديدة. يعتمد وقت وصول التنبيه على فترة الفحص المختارة.

---

## 🚀 خطوات التشغيل

### الخطوة 1: إنشاء بوت تلجرام

1. افتح تلجرام وابحث عن **@BotFather**
2. أرسل `/newbot`
3. اختر اسماً للبوت (مثال: `LMS Monitor`)
4. اختر username للبوت (مثال: `mutah_lms_bot`)
5. ستحصل على **Token** - احفظه

### الخطوة 2: إضافة Token إلى ملف .env

افتح ملف `.env` وضع الـ Token:

```
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
```

### الخطوة 3: تثبيت المتطلبات

```powershell
pip install -r requirements.txt
```

### الخطوة 4: تشغيل البوت

```powershell
python bot.py
```

---

## 📱 كيفية الاستخدام

بعد تشغيل البوت، افتح تلجرام وابدأ المحادثة:

| الأمر | الوظيفة |
| `/start` | تشغيل البوت وفتح لوحة التحكم الرئيسية بالأزرار |
| الأزرار | تسجيل الدخول، إدارة المواد، تشغيل/إيقاف المراقبة، الفحص اليدوي، الإعدادات والإحصائيات |

أثناء تشغيل المراقبة، يرسل البوت طلباً خفيفاً لنظام الجامعة كل دقيقتين للمحافظة على الجلسة نشطة. إذا انتهت الجلسة، يوقف الفحص ويرسل تنبيهاً مع زر إعادة تسجيل الدخول؛ تبقى المواد وإعدادات المراقبة محفوظة، ويستأنف البوت المتابعة بعد نجاح الدخول.

## 📂 هيكل المشروع

```
LMS_Monitor/
├── bot.py            # البوت الرئيسي
├── lms_scraper.py    # سحب البيانات من LMS
├── monitor.py        # محرك المراقبة الدورية
├── database.py       # قاعدة البيانات SQLite
├── config.py         # الإعدادات
├── reminder.py       # تذكيرات مواعيد التسليم
├── .env              # متغيرات البيئة (Token)
├── requirements.txt  # المتطلبات
└── lms_monitor.db    # قاعدة البيانات (تُنشأ تلقائياً)
```

## ⚙️ إعدادات متقدمة

في ملف `config.py`:

```python
# الفترة الافتراضية للحسابات الجديدة (بالدقائق)
CHECK_INTERVAL_MINUTES = 5
```

يمكن تغيير الفترة من إعدادات البوت؛ الحسابات الحالية تحتفظ بالفترة المحفوظة لديها.

## 🛡️ الأمان

- بيانات LMS تُحفظ في قاعدة البيانات المضبوطة: SQLite محلياً أو PostgreSQL عند ضبط `DATABASE_URL` أو `DIRECT_URL`. كلمات المرور مخزنة حالياً دون تشفير داخل قاعدة البيانات.
- يحاول البوت حذف رسائل بيانات الدخول من تيليجرام بعد استلامها.
